# 对比数据生成脚本说明

## 概述

`generate_comparison_data.py` 用于生成两种不同格式、不同维度、不同场景的博弈轨迹数据，并提供详细的对比可视化方法，用于向领导展示数据集的差异。

## 功能特点

### 数据集1：标准空战场景
- **格式**：JSON格式
- **维度**：12维状态空间（标准空战状态）
- **场景**：空战追击/规避场景
- **特点**：少量样本（50条），中等长度（60步）
- **适用**：基础算法验证、快速原型开发

### 数据集2：扩展多机协同场景
- **格式**：NPY格式（NumPy数组）
- **维度**：18维状态空间（扩展状态，包含相对距离、相对速度、能量状态等）
- **场景**：多机协同空战场景
- **特点**：大批量样本（200条），较长轨迹（100步）
- **适用**：复杂场景建模、大规模训练

## 使用方法

### 运行脚本

```bash
cd /Users/bluixe/Code/afruit
python afruits/generate_comparison_data.py
```

### 输出文件

脚本会在 `data/comparison/` 目录下生成以下文件：

1. **数据文件**：
   - `dataset1_air_combat.json` - 数据集1（JSON格式）
   - `dataset2_extended_combat.npy` - 数据集2（NPY格式）
   - `dataset2_meta_data.json` - 数据集2的元数据

2. **对比可视化图表**（保存在 `data/comparison/comparison_visualizations/`）：
   - `1_data_scale_comparison.png` - 数据规模对比（轨迹数量、长度）
   - `2_dimension_comparison.png` - 状态维度对比
   - `3_trajectory_2d_comparison.png` - 轨迹2D可视化对比
   - `4_trajectory_3d_comparison.png` - 轨迹3D可视化对比
   - `5_distribution_comparison.png` - 数据分布对比（速度、动作分布）
   - `6_comparison_table.png` - 综合对比表格

## 对比维度说明

### 1. 格式差异
- **数据集1（JSON）**：人类可读，易于调试和查看，适合小规模数据
- **数据集2（NPY）**：二进制格式，加载速度快，适合大规模数据

### 2. 维度差异
- **数据集1（12维）**：基础状态空间
  - 我方：位置(x,y,z)、速度(v)、航向(psi)、垂直速度(vz)
  - 对手：位置(x,y,z)、速度(v)、航向(psi)、垂直速度(vz)
  
- **数据集2（18维）**：扩展状态空间
  - 包含数据集1的所有12维
  - 额外6维：相对距离、相对速度、角度差、我方能量、对手能量、高度差

### 3. 场景差异
- **数据集1**：标准空战场景，包含追击、规避、巡航等典型行为
- **数据集2**：扩展多机协同场景，包含更丰富的状态信息，适用于复杂场景分析

### 4. 规模差异
- **数据集1**：50条轨迹，每条60步（适合快速验证）
- **数据集2**：200条轨迹，每条100步（适合大规模训练）

## 可视化图表说明

### 1. 数据规模对比图
展示两个数据集的轨迹数量和轨迹长度差异，直观显示数据规模。

### 2. 维度对比图
展示状态空间的维度差异，说明数据集2包含更多扩展特征。

### 3. 轨迹可视化对比
- **2D对比**：展示轨迹在XY平面的投影
- **3D对比**：展示轨迹在三维空间中的完整路径

### 4. 数据分布对比
- **速度分布**：展示两个数据集中速度值的分布情况
- **动作分布**：展示动作选择的分布情况

### 5. 对比表格
综合展示两个数据集的所有关键属性，便于快速对比。

## 自定义参数

## 使用场景

这些对比数据可用于：
- 向领导展示不同数据格式、维度和场景的差异
- 说明小样本与大批量数据的区别
- 演示数据增强前后的效果对比
- 验证算法在不同数据规模下的表现
